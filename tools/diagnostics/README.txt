ДИАГНОСТИКА ГЛЮКОБОЯ — ОТДЕЛЬНАЯ ПЕРЕНОСНАЯ ПРОГРАММА

Файл Glukoboy.Diagnostics.exe можно запускать из любой удобной папки.
Класть его рядом с игрой не обязательно. Установка и права администратора
не нужны. На Windows требуется .NET Framework 4.5 или новее.

КАК СОБРАТЬ ОТЧЁТ

1. Откройте Glukoboy.Diagnostics.exe. Запись начинается автоматически.
2. Нажмите «Свернуть в значок» и пользуйтесь компьютером как обычно.
   Крестик тоже прячет окно в значок рядом с часами Windows.
   Если значка не видно, раскройте стрелку скрытых значков.
3. Дождитесь включения ночного режима или момента, когда ребёнок его обойдёт.
   До записи проблемного момента не нажимайте родительские горячие клавиши:
   это может изменить состояние, которое нужно исследовать.
4. Подождите ещё 10–20 секунд. Дважды нажмите значок сборщика.
5. Нажмите «Сохранить отчёт и выйти». Дождитесь сообщения о готовности.
6. Пришлите полученный Bubliklyuk-report-....zip в чат.

ZIP обычно появится на рабочем столе. Если он недоступен, находится на
сетевом диске или в известной папке OneDrive — в документах или рядом
с папками записей на локальном диске. После сохранения откроется проводник с ZIP;
точный путь также будет показан в сообщении. Сам сборщик ничего не отправляет.

Если системная проверка зависнет, через пять секунд ожидания сборщик начнёт
сохранять доступную часть отчёта. В collection-state.txt внутри ZIP будет
отмечено, что отчёт неполный. Ошибка сохранения не удаляет исходные данные:
окно покажет их папку и позволит повторить попытку.

ЧТО СБОРЩИК ДЕЛАЕТ

Проверяет состояние примерно каждые полсекунды. Записывает состояние
процессов и окон Глюкобоя, название активной программы, сведения о ночном
режиме, журнал ошибок errors.log Глюкобоя и разрешённые поля расписания.
Чтение файлов игры ограничено; другие настройки целиком не копируются.
Проверка прекращается после сохранения, достижения предела размера
или через шесть часов. До сохранения программа остаётся в значке.

Сборщик не записывает нажатия клавиш, снимки экрана или звук, не запускает
и не закрывает игру, не меняет реестр и автозагрузку, не выходит в сеть.
Сохраняются только локальные файлы. Сам сборщик не загружает информационные
файлы или отчёты в интернет.

Исходные записи находятся в профиле текущего пользователя:
%LOCALAPPDATA%\GlukoboyDiagnostics\Reports\дата-время-случайный_номер
Они остаются на месте после создания ZIP. При завершении работы Windows
сборщик выходит без ожидания зависших проверок; незавершённая запись
может остаться только в этой папке.

ДЛЯ СБОРКИ И ПРОВЕРКИ

build.cmd собирает Glukoboy.Diagnostics.exe штатным компилятором .NET Framework.
Необязательный первый аргумент — полный путь к выходному EXE.
Glukoboy.Diagnostics.exe --render "C:\путь\preview.png" создаёт изображение
окна для проверки оформления. В этом режиме сбор данных не запускается.
