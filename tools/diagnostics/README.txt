ДИАГНОСТИКА ГЛЮКОБОЯ — АВТОМАТИЧЕСКАЯ ФОНОВАЯ ЗАПИСЬ

После обновления игра сама запускает диагностику в фоне: отдельно запускать
сборщик не нужно. Окно не открывается, рядом с часами появляется значок.
Если игра закроется или исчезнет, диагностика продолжит запись.
Установка и права администратора не нужны, требуется .NET Framework 4.5+.

КАК СОБРАТЬ ОТЧЁТ

1. После запуска игры диагностика уже работает в фоне.
2. Пользуйтесь компьютером как обычно. Значок диагностики находится рядом
   с часами Windows; если его не видно, раскройте стрелку скрытых значков.
3. Дождитесь включения ночного режима или момента, когда ребёнок его обойдёт.
   До записи проблемного момента не нажимайте родительские горячие клавиши:
   это может изменить состояние, которое нужно исследовать.
4. Подождите ещё 10–20 секунд. Дважды нажмите значок сборщика.
5. Нажмите «Сохранить отчёт и выйти». Дождитесь сообщения о готовности.
6. Пришлите полученный Bubliklyuk-report-....zip в чат.

ZIP обычно появится на рабочем столе. Если он недоступен, находится на
сетевом диске или в известной папке OneDrive — в документах или рядом
с папками записей на локальном диске. После сохранения откроется проводник с ZIP;
точный путь также будет показан в сообщении. Сам сборщик ничего не отправляет.

Если системная проверка зависнет, через пять секунд ожидания сборщик начнёт
сохранять доступную часть отчёта. В collection-state.txt внутри ZIP будет
отмечено, что отчёт неполный. Ошибка сохранения не удаляет исходные данные:
окно покажет их папку и позволит повторить попытку.

ЧТО СБОРЩИК ДЕЛАЕТ

Проверяет состояние примерно каждые полсекунды. Записывает состояние
процессов и окон Глюкобоя, название активной программы, сведения о ночном
режиме, журнал ошибок errors.log Глюкобоя и разрешённые поля расписания.
Чтение файлов игры ограничено; другие настройки целиком не копируются.
Одна часть записи ограничена шестью часами или 20 МиБ. Затем начинается
следующая часть: диагностика, запущенная утром, продолжит работать вечером.
Хранятся до восьми последних частей — до 160 МиБ, примерно 48 часов
непрерывной работы. Частые перезапуски или большой поток событий сокращают
историю. В ZIP включаются все доступные последние части, в том числе
запись по обе стороны смены части.

Сохранение останавливает текущий сборщик. При следующем запуске игры
начнётся новая фоновая запись. Крестик и сворачивание только прячут окно.
Повторный запуск игры не создаёт второй сборщик.

Сборщик не записывает нажатия клавиш, снимки экрана или звук, не запускает
и не закрывает игру, не меняет реестр и автозагрузку, не выходит в сеть.
Сохраняются только локальные файлы. Сам сборщик не загружает информационные
файлы или отчёты в интернет.

Исходные записи находятся в профиле текущего пользователя:
%LOCALAPPDATA%\GlukoboyDiagnostics\AutomaticCapture
Сборщик удаляет только свои распознанные старые части в этой папке.
Неизвестные файлы, папки и ссылки он не удаляет. Если очистить свою старую
часть не удалось, запись остановится, а доступные данные можно сохранить.
Готовые ZIP автоматически не удаляются. При завершении работы Windows
сборщик выходит без ожидания зависших проверок; незавершённая запись
может остаться только в этой папке.

ОТДЕЛЬНЫЙ РУЧНОЙ ЗАПУСК

Glukoboy.Diagnostics.exe можно открыть из любой удобной папки.
Если диагностика уже работает, откроется её существующее окно.
Если сборщика нет, начнётся отдельная запись до шести часов / 20 МиБ.
Она сохраняется в %LOCALAPPDATA%\GlukoboyDiagnostics\Reports;
эти отдельные записи не удаляются автоматической очисткой.

ДЛЯ СБОРКИ И ПРОВЕРКИ

build.cmd собирает Glukoboy.Diagnostics.exe штатным компилятором .NET Framework.
Необязательный первый аргумент — полный путь к выходному EXE.
Glukoboy.Diagnostics.exe --render "C:\путь\preview.png" создаёт изображение
окна для проверки оформления. В этом режиме сбор данных не запускается.
--background используется игрой для фонового запуска без открытия окна.
--render-background "C:\путь\preview.png" проверяет настоящий цикл сообщений
скрытого запуска, сохраняет результаты в preview.png.state.txt, затем
рисует окно вне экрана без активации. Превью не запускает сбор данных
и не создаёт значок, mutex или папки записей.
tests\run-background.ps1 проверяет ротацию, хранение, ZIP и скрытый запуск
на временных искусственных данных; реальная игра и сборщик не запускаются.
