# Черновики прежних уровней

Снимок исходников, банка чтения и настроек версии 1.6.4 перед добавлением диктантов.
Эти файлы не включаются в сборку из папки drafts. Здесь сохранены уровни 1–3 классов
и прежние карточки «прочитай и ответь» для возможной дальнейшей работы.

В действующей программе одна сложность: текущий набор для Дани, 1 класс, вторая четверть.
Карточки на понимание прочитанного заменены двумя диктантами в каждой атаке.
Прежние значения Grade/Level и личный tasks.txt не выбирают другой уровень и не меняют банк диктантов.
