# Изменения

## 1.6.0

- 60 новых карточек для `Grade=1`, `Level=2`: 30 «лишний предмет», 15 по описанию, 15 последовательностей. Четыре варианта ответа, крупные картинки и кнопка «Помоги».
- Только в выборе вариантов: после двух ошибок карточка заменяется без зачёта. Решённые задания сохраняются, позиция ответа меняется, быстрые повторные нажатия не учитываются. Задания с вводом слова или числа сохраняют неограниченные попытки.
- Четыре вечерних сценария с 21:00 до 07:00: перегрев, ремонт, очистка от глюков и большое обновление. Сюжет сохраняется на всю ночь и чередуется по датам. `NightModes=overheat` оставляет только перегрев.
- Новые появления, реакции и три финала БублиГлюка: шарик, тележка и щит. `AnimationLevel=0/1/2` управляет активностью движений.
- Обновлены README и страница GitHub Pages, добавлены проверки поведения и отрисовки.

Обновление: запустите `Обновить.cmd` рядом с программой или распакуйте `Glukoboy.zip` поверх существующей папки после выхода через Ctrl+Alt+Q. Настройки сохраняются. Для новых заданий задайте `Grade=1` и `Level=2` в `settings.ini` и перезапустите программу. Новые параметры необязательны: старые INI поддерживаются.
